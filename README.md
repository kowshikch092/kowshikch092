## 🚀 Featured Projects

### 1. [TripMate – Multi-Agent AI Travel Planner using MCP](https://github.com/kowshikch092/TripMate-Multi-Agent-AI-Travel-Planner-using-MCP)

A multi-agent travel-planning application orchestrated with LangGraph and MCP.

- Built a workflow with five specialized agents for flight, hotel, weather, itinerary, and final-response tasks.
- Integrated three MCP servers: AviationStack (local), Tavily (remote), and a custom Weather MCP server.
- Used asynchronous processing to coordinate agent tasks and generate a trip plan in under one minute in the tested workflow.
- Implemented PostgreSQL-backed persistence and shared cross-agent state to maintain context during trip planning.

**Technologies:** Python, LangGraph, MCP, PostgreSQL, asyncio, LLMs.

### 2. [NutriRAG – RAG-Based Nutrition Chatbot](https://github.com/kowshikch092/RAG-Nutritional-Chatbot)

A Retrieval-Augmented Generation chatbot that answers nutrition-related questions using a corpus of more than 1,200 pages.

- Extracted and chunked PDF content using PyMuPDF and document-processing techniques.
- Generated 384-dimensional embeddings with the `all-MiniLM-L6-v2` Sentence Transformer model.
- Stored and retrieved embeddings using Supabase pgvector for semantic search.
- Integrated Groq's Llama 3.3 70B model to generate answers grounded in retrieved content, with page-level citations.

**Technologies:** Python, PyMuPDF, Sentence Transformers, all-MiniLM-L6-v2, Supabase, pgvector, Groq, Llama 3.3 70B, Next.js.

### 3. [SmartCare AI – Memory-Enhanced Support Assistant](https://github.com/kowshikch092/Why-I-recall-hindsight-memory-before-running-RAG)

A support-assistant project exploring the use of Hindsight memory before knowledge-base retrieval. The linked repository contains the accompanying project write-up.

- Uses Hindsight to recall relevant customer context before running RAG.
- Retrieves troubleshooting information from a knowledge base and uses web search as a fallback when needed.
- Focuses on recalling useful facts from previous interactions rather than treating the entire conversation history as memory.

**Technologies:** Python, Hindsight, RAG, LLMs, LangGraph, Tavily.
