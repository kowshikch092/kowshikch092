## 🚀 Featured Projects

### 1. [TripMate – Multi-Agent AI Travel Planner](https://github.com/kowshikch092/TripMate-Multi-Agent-AI-Travel-Planner-using-MCP)

A travel-planning application built around specialized agents and external tools.

- Uses **LangGraph** to orchestrate the travel-planning workflow.
- Integrates **MCP** tools for flight information, web research, and weather-related information.
- Uses PostgreSQL-backed persistence for longer-term application context.

**Technologies:** Python, LangGraph, MCP, PostgreSQL, LLMs, FastAPI.

### 2. [NutriRAG – Retrieval-Augmented Nutrition Assistant](https://github.com/kowshikch092/RAG-Nutritional-Chatbot)

A RAG application that answers nutrition questions using a textbook corpus of approximately **1,200 pages**.

- Extracts and chunks PDF content for retrieval.
- Generates local embeddings using **all-MiniLM-L6-v2**.
- Uses **Supabase pgvector** for semantic search.
- Uses **Groq Llama 3.3 70B** to generate answers grounded in retrieved passages, with page-level citations.

**Technologies:** Python, PyMuPDF, Sentence Transformers, Supabase, pgvector, Groq, Next.js, TypeScript.

### 3. [SmartCare AI – Hindsight Memory Before RAG](https://github.com/kowshikch092/Why-I-recall-hindsight-memory-before-running-RAG)

A customer-support assistant designed to use relevant customer memory before retrieving troubleshooting knowledge.

- Recalls customer-specific context from **Hindsight** before knowledge-base retrieval.
- Uses RAG over a troubleshooting manual and falls back to web search when relevant manual content is unavailable.
- Extracts useful facts from conversations for future recall rather than retaining every turn as memory.
- Uses LangGraph to coordinate the workflow.

**Technologies:** Python, Hindsight, LangGraph, RAG, ChromaDB, Groq, Tavily, Streamlit.
